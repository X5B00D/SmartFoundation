# خطة تنفيذ التوثيق بعد الجرد

## قاعدة الاستكمال

تقرأ كل مهمة `Documentation-Progress.json` ونتائج `Documentation/Work` قبل البدء، وتحدّثها عند الانتهاء. لا يعاد تحليل مرحلة مكتملة إلا إذا ظهرت علاقة جديدة تؤثر فيها.

## المهام المقترحة

1. تحليل المعمارية والمكونات المشتركة وتدفق الطلب والبيانات.
2. تحليل الأمان والمصادقة والترخيص وإدارة الجلسة.
3. توثيق ControlPanel.
4. توثيق Housing: التعريفات.
5. توثيق Housing: إجراءات السكن.
6. توثيق Housing: قوائم الانتظار والاستيراد.
7. توثيق IncomeSystem.
8. توثيق ElectronicBillSystem.
9. توثيق Home وLogin.
10. تحليل قاعدة البيانات وتتبع الجداول والـ Views والـ Functions والـ Triggers.
11. إنشاء ERD والرسومات المعمارية ورسومات Workflows المثبتة.
12. توثيق التقارير والتكاملات والتشغيل والنشر والنسخ الاحتياطي واستكشاف الأخطاء.
13. إعداد دليل المطور ودليل المستخدم.
14. تجميع Word وتدقيقه بصرياً.
15. إنشاء PDF وتنفيذ Coverage Audit والتحقق النهائي.

## ضوابط التنفيذ

- جميع تحليلات قاعدة البيانات قراءة فقط.
- لا تعرض أسراراً أو Connection Strings كاملة.
- لا تعدل إلا الملفات داخل `Documentation/` طوال مشروع التوثيق.
- تميز الوثيقة بين المثبت والمستنتج وغير المتحقق منه.
- البرامج المؤجلة لا تدخل في Coverage.
