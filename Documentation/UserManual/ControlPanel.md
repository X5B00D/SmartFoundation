# دليل مستخدم ControlPanel

## قبل البدء

يجب تسجيل الدخول وأن تكون لديك صلاحية الصفحة وصلاحية العملية المطلوبة. عدم ظهور زر يعني غالباً غياب الصلاحية. حتى إن أرسل طلب يدوياً، تعيد البوابة فحص الصلاحية قبل التنفيذ.

## إدارة البرامج والقوائم والصفحات

### إضافة برنامج

1. افتح `PagesManagment`.
2. من قسم البرامج اختر إضافة.
3. أدخل الاسمين العربي والإنجليزي والوصف والرابط والأيقونة والترتيب.
4. احفظ. يجب أن تكون الأسماء فريدة والترتيب موجباً.

### إضافة قائمة أو صفحة

1. اختر البرنامج.
2. لإضافة قائمة، أدخل الاسم والوصف والترتيب.
3. لإضافة صفحة، اختر البرنامج أو القائمة الأب، ثم أدخل الاسم والرابط والوصف والترتيب ومستوى الوصول.
4. احفظ؛ تنشئ الصفحة تلقائياً الموزع والربط اللازمين.

### تعريف عمليات الصفحة

1. حدد الصفحة.
2. اختر إضافة صلاحية صفحة.
3. أدخل الاسم الوظيفي العربي والاسم الإنجليزي الذي سيطابق `ActionType` ومستوى التفويض.
4. استخدم تعديل/تعطيل لتغيير المستوى أو الحالة. التعطيل لا يحذف السجل نهائياً.

## إدارة الصلاحيات

1. افتح `Permission` واختر نوع الهدف: مستخدم، موزع، دور، إدارة، أو مستوى تنظيمي.
2. أكمل معيار البحث حتى يظهر الجدول.
3. لإضافة صلاحية واحدة، اختر البرنامج ثم الصفحة ثم العملية، ويمكن تحديد تاريخ بداية ونهاية وملاحظة.
4. لإضافة وصول كامل، اختر الموزع؛ سيضيف النظام العمليات غير الموجودة مسبقاً فقط.
5. لتعديل صلاحية، حدد صفاً واحداً وعدل المدة أو الملاحظة.
6. لإيقافها، حدد صفاً واحداً واضغط حذف/إيقاف ثم أكد. العملية تعطيل منطقي.

ينبغي استخدام Full Access بحذر لأنه يوسع نطاق العمليات دفعة واحدة. إذا رفض النظام الحفظ برسالة عدم امتلاك الصلاحية، اطلب من مسؤول أعلى منح ActionType المطلوب.

## إدارة المستخدمين

### إضافة مستخدم

1. افتح `Users` واختر إضافة مستخدم.
2. أدخل الهوية الوطنية والرقم العام وتواريخ الهوية والميلاد.
3. أدخل الاسم العربي، والإنجليزي إن توفر.
4. اختر صلاحية النظام ونوع المستخدم والإدارة والموزع وبيانات التصنيف.
5. احفظ. يجب ألا تتكرر الهوية أو الرقم العام.

### تعديل أو تعطيل مستخدم

1. حدد مستخدماً واحداً.
2. اختر تعديل، غيّر البيانات، واكتب سبب التعديل.
3. تعديل الهوية متاح فقط لمن تظهر له ملاحظة امتلاك `UPDATENATIONALID`.
4. للتعطيل اختر حذف/إيقاف، اكتب السبب ثم أكد. المستخدم يعطّل ولا يحذف فيزيائياً.

### إعادة كلمة المرور

حدد المستخدم واختر إعادة كلمة المرور إذا كانت العملية ظاهرة وممنوحة لك. يمر الطلب إلى الإجراء المتخصص ويكتب أثر العملية. لا تشارك كلمة المرور أو تسجلها في الملاحظات.

## رسائل شائعة

- “لا تملك صلاحية”: صلاحية ActionType غير ممنوحة حتى لو ظهر عنصر في الواجهة.
- “الاسم مستخدم مسبقاً”: يوجد برنامج/قائمة/صفحة/صلاحية نشطة بالقيمة نفسها.
- “العملية غير مسجلة”: ActionType لا يطابق فرعاً معروفاً في البوابة أو الإجراء.
- عدم ظهور جدول Permission: لم تكتمل حقول معيار البحث المختار.
- فشل تغيير الهوية: تحقق من صلاحية `UPDATENATIONALID` ومن عدم تكرار الهوية.
